# API Ampara (C#/.NET) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a API do Ampara (regras, dados, tempo real, escuta do chaveiro por MQTT, BO, ponte com a polícia, risco) com testes xUnit, pronta para o motor PII/taint (plano 03) plugar sem refatorar.

**Architecture:** Solution em camadas (`Domain` com entidades de comportamento e `IGatilho`; `Application` com serviços por interface e `IAmparaDb`; `Infrastructure` com EF Core/Npgsql, MQTTnet, HttpClient da Ponte, cifra; `Api` com Minimal APIs, JWT, SignalR e Scalar). Tempo sempre por `TimeProvider` (escalada de 60 s, bloqueio de 15 min e retenção de 7 dias testáveis com `FakeTimeProvider`). O pipeline já traz `CorrelacaoMiddleware` e `PiiRequestMiddleware` (este só chama `next`) e as interfaces `ITaintGuard`, `IAcessoIndevido`, `IImeiRevelador` e `IModeradorRelato` (pasta `api/Ampara.Application/Cyber/`) com implementações no-op; o plano 03 substitui só as implementações.

**Tech Stack:** .NET (net10.0 se o SDK 11 compilar, senão net11.0), ASP.NET Core Minimal APIs, EF Core + Npgsql (+ Sqlite só nos testes), SignalR, MQTTnet, JWT Bearer, Scalar/OpenAPI, xUnit, `Microsoft.Extensions.TimeProvider.Testing`.

**Spec:** `docs/superpowers/specs/2026-11-14-ampara-design.md` (v3) e, como fonte única de rotas/nomes/formatos/variáveis, `docs/superpowers/plans/2026-11-14-00-indice-e-contratos.md` (vence em divergência). Contrato do chaveiro: `iot/docs/contrato-mqtt.md`.

## Review Focus

1. E-mail com maiúsculas/espaços no cadastro e no login: deve entrar e não duplicar conta → teste na Tarefa 4.
2. Lote de rota inválido (lat/lng fora da faixa, `em` no futuro ou > 7 dias, > 500 pontos, retransmissão do mesmo ponto): rejeita o lote inteiro ou ignora duplicado, nunca grava parcial → Tarefa 10.
3. Mensagem MQTT malformada (JSON inválido, `deviceId` do tópico ≠ do payload, tipo desconhecido, payload enorme, `ts` nulo): não derruba o cliente, não cria ocorrência, não responde `ack` → Tarefa 14.
4. Vítima sem guardiões aceitos dispara o gatilho, ou dois gatilhos seguidos (chaveiro + web): ocorrência registrada sem erro e **uma** ocorrência aberta por vítima → Tarefa 11.
5. Ponte fora do ar ao compartilhar com a polícia: 502 com problem+json, nada marcado como enviado, nova tentativa funciona; BO sem momento marcado → 409 → Tarefas 16 e 18.
